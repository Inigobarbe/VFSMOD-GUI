  Potential Causes for Failed UH and/or VFSM Simulations.

The vfsmod-w system consists of a VISUAL BASIC front end program
to help the user setup inputs and perform various analysis tasks
that one would do with a model. The inputs for the source area
hydrology program, UH, and the inputs for the filter strip modeling
program, VFSM, are built by various methods from within the front
end program. The methods are:

  1) manual input by editing single input data sets, 
  2) automaticcally generating inputs for performing sensitivity 
     analysis with either vfsm only or uh and vfsm together, 
  3) automaticcally generating inputs for performing uncertainty 
     analysis with either vfsm only or uh and vfsm together, 
  4) automaticcally generating inputs for a design analysis.

For failures in each of these simulation modes, there are a range
of input problems that can cause the programs UH and VFSM to fail
to complete correctly.

To debug failures, create a single simulation for uh and/or vfsm
that can duplicate the failure. Run these simulations and note
any errors. You can open the partial output files from windows
explorer see at what point the simulation failed.  Send us
e-mail via the web site detailing your problem. We will respond and
instruct you on which files to forward so that we can help
you debug your problem.
